# Laboratory 06 – Cloud Deployment Engineer

**Name:** Angelo Gutoman  
**Course & Section:** BSIT 4-L

## Mission Overview

In this laboratory activity, I will learn how to deploy a multi-tier application using Docker Compose. I will configure Nextcloud as the web application and MariaDB as its database, allowing both containers to communicate with each other.

## Objectives

- Understand the concept of a two-tier architecture.
- Create a `docker-compose.yml` configuration file.
- Deploy Nextcloud and MariaDB using Docker Compose.
- Access the Nextcloud setup page through port forwarding.
- Document the deployment process and Infrastructure as Code principles.

## Commands Executed

The commands used in this activity will include:

- `mkdir nextcloud-deployment`
- `cd nextcloud-deployment`
- `nano docker-compose.yml`
- `docker-compose up -d`
- `docker-compose ps`
- `docker-compose down`

## Skills Learned

I will practice writing YAML configuration files, deploying multiple containers, connecting a web application to a database, and documenting cloud infrastructure using Markdown and GitHub.

## Mission Reflection

My reflection will discuss the benefits of Docker Compose, the importance of correct YAML indentation, the use of environment variables, and what I learned about cloud computing.

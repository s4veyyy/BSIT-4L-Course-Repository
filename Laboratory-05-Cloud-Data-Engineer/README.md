**Name:** Angelo Gutoman
**Course & Section:** BSIT 4-L

## Mission Overview
In this laboratory activity, I learned about Object Storage and how it is used to store large amounts of unstructured data such as images, videos, and backups. I deployed an S3-compatible object storage server called MinIO using Docker, accessed its web console, created a storage bucket, and uploaded a sample file.

## Objectives
- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server using MinIO and Docker.
- Access a cloud service through a web interface using port forwarding.
- Create a storage bucket and upload objects to the cloud.
- Document cloud storage operations using Markdown.
- Continue expanding my GitHub Cloud Computing Portfolio.

## Skills Learned
I learned how to compare different types of cloud storage, deploy MinIO using Docker, access a cloud service through a specific port, create a storage bucket, and upload files to object storage.

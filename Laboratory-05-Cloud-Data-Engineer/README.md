# Laboratory 05 – Cloud Data Engineer

**Name:** Angelo Gutoman  
**Course & Section:** BSIT 4-L

## Mission Overview

In this laboratory activity, I will learn about Object Storage and how it is used to store large amounts of unstructured data such as images, videos, and backups. I will also deploy an S3-compatible object storage server called MinIO using Docker, access its web console, create a storage bucket, and upload a sample file.

## Objectives

- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server using MinIO and Docker.
- Access a cloud service through a web interface using port forwarding.
- Create a storage bucket and upload objects to the cloud.
- Document cloud storage operations using Markdown.
- Continue expanding my GitHub Cloud Computing Portfolio.

## Tools Used

- KillerCoda Playground
- Docker
- MinIO
- GitHub
- Web Browser
- Ubuntu/Linux Command Line

## Skills Learned

I will learn how to compare different types of cloud storage, deploy MinIO using Docker, access a cloud service through a specific port, create a storage bucket, and upload files to object storage. I will also improve my Linux command-line skills and continue organizing my cloud computing activities in my GitHub portfolio.

## Challenges Encountered

I may encounter challenges when deploying MinIO, accessing the web console, or configuring the Docker environment. I will solve these challenges by carefully following the required commands and checking the terminal output after each step.

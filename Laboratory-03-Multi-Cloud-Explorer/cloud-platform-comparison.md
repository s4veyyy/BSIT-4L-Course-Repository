## 2. Comparison Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest portfolios of cloud services among the three major providers. It provides services covering computing, storage, databases, networking, security, analytics, artificial intelligence, application development, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies because it is part of the Microsoft ecosystem. Organizations using Windows Server, Microsoft 365, Active Directory, and other Microsoft products can connect these environments with Azure services.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in artificial intelligence, machine learning, data analytics, and Kubernetes-related technologies. Its Google Kubernetes Engine (GKE) provides managed Kubernetes capabilities, while Google Cloud also offers services and infrastructure designed for AI and machine learning workloads.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Microsoft Azure because of its strong enterprise integration, broad range of services, and support for hybrid cloud environments. Azure is also a practical choice for organizations that already use Microsoft technologies because it can integrate cloud services with existing Windows and Microsoft-based infrastructure.

## 4. Service Comparison Summary

### Virtual Machine

Amazon EC2, Azure Virtual Machines, and Google Compute Engine all provide virtual computing resources in the cloud. They allow organizations to run operating systems and applications without maintaining the physical servers themselves.

### Object Storage

Amazon S3, Azure Blob Storage, and Google Cloud Storage provide object storage for files and unstructured data. They can be used for applications such as backups, media storage, archives, application data, and large datasets.

### Identity Management

AWS IAM, Microsoft Entra ID, and Google Cloud Identity provide identity and access management capabilities. These services help organizations manage users, identities, authentication, and access permissions for cloud resources and applications.

### SQL Database

Amazon RDS, Azure SQL Database, and Google Cloud SQL provide managed relational database capabilities. These services reduce the amount of infrastructure administration required when deploying and maintaining SQL-based databases.

### Kubernetes

Amazon EKS, Azure Kubernetes Service, and Google Kubernetes Engine provide managed Kubernetes environments. They allow organizations to deploy, manage, and scale containerized applications using Kubernetes technology.

---

## 5. Overall Comparison

AWS, Microsoft Azure, and Google Cloud Platform provide similar categories of cloud services, including computing, storage, networking, databases, identity management, and container orchestration. However, each provider has different strengths that may make it more appropriate for specific organizations or workloads.

AWS is a strong choice for organizations that need a very broad selection of cloud services and flexible infrastructure options. Azure is particularly suitable for enterprises that depend on Microsoft technologies and require strong enterprise or hybrid-cloud integration. Google Cloud is a strong option for organizations that prioritize artificial intelligence, machine learning, data analytics, Kubernetes, and cloud-native application development.

The best cloud platform therefore depends on the organization's technical requirements, existing infrastructure, budget, workforce skills, security requirements, and long-term business goals.
